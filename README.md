# متحف حبّنا ❤ (النسخة 2)

متحف ثلاثي الأبعاد لصوركن، بتمشوا فيه سوا:

- **شاشة البداية** «متحف حبّنا — من … إلى …» مع زر ملء الشاشة.
- **شاشة «شكلكن»** قدام بناية المتحف (أعمدة، باب أحمر، رايات عليها أساميكن). بتختار مين إنت، وبتعدّل شكلك وشكل الشخص التاني: البشرة، الشعر (كيرلي، طويل، ذيل حصان…) ولونه، اللبس (قميص وصدرية، فستان، هودي…) وألوانه. وبتختار ستايل المتحف: **عصري** (أبيض وأسود متل الفيديو) أو **كلاسيكي** (أحمر وذهبي).
- **الباب بينفتح** لما تقرّبوا، وبتفوتوا من برّا لجوّا.
- **الشخص التاني بيمشي جنبك**، فوق راسه اسمه وفقاعات كلام («بحبك ❤️»، «بتتذكر هاليوم؟ 🥹»…)، وبيردّ على شو عم يصير.
- **اللوحات مغطاية بستارة** بتنرفع لما تقرّب، وفي عدّاد للذكريات.
- **وضع التأمّل**: E على أي لوحة بتقرّب الكاميرا عليها. بيطلع العنوان والتاريخ والوصف، والأسهم بتنقّلك بين الصور، و⤢ بتفتح الصورة بالدقة الكاملة.
- **الأحاجي 🧩**: لوحات مقفولة قدامها قلب عم يلمع (بازل منزلق، بازل تبديل، لعبة ذاكرة، سؤال وجواب).
- **لوحة الإهداء 💌** عند المدخل: «مجموعة دائمة — إلى … — دائماً، …».
- **المقاعد 🪑**: بتقعدوا سوا وبتتفرجوا عاللوحات.
- **قاعة القلب**: شاشة كبيرة بتعرض كل صوركن (عرض متحرك)، قدامها مقعد، وورود عم تنزل، وقلب على الأرض. لما توقفوا عليه بترقصوا 💃 وبتطلع رسالة النهاية.
- **زر 💃** لترقصوا بأي مكان.
- **موسيقى**: إذا حطيت `music/music.mp3` بتشتغل، وإذا لأ في موسيقى «علبة موسيقى» مدمجة هادية.
- ظلال حقيقية، وبيشتغل عالموبايل (جويستيك + زر ❤).

## 📸 وين بحط الصور؟

```
museum/
  photos/          ← هون كل الصور (jpg / png / webp)
  music/music.mp3  ← (اختياري) أغنيتكن
  config.js        ← الأسماء، الإهداء، العناوين، الأحاجي، الحكي، الستايل
  start.bat        ← دبل كليك ليشتغل
```

- الترتيب حسب اسم الملف: `01.jpg`, `02.jpg` …
- `01-أول لقاء.jpg` ← «أول لقاء» بيصير عنوان اللوحة.
- عدد القاعات بيزيد لحالو حسب عدد الصور.

## ▶️ التشغيل

دبل كليك على **`start.bat`** وبيفتح المتصفح. ما بدو تنزيل أي شي.
ضفت صور؟ حدّث الصفحة (F5).

## ✏️ أهم الإعدادات (config.js)

| الإعداد | شو بيعمل |
|---|---|
| `him` / `her` | الأسماء |
| `theme` | `"modern"` أو `"classic"` |
| `dedication` | نص لوحة الإهداء |
| `endingTitle` / `endingMessage` | رسالة النهاية |
| `herSays` / `himSays` | الحكي يلي بيطلع بالفقاعات |
| `photos` | عنوان/تاريخ/وصف لكل صورة |
| `puzzles` | الأحاجي (أو `autoPuzzles: true` بتعملهن لحالها) |
| `looks` | الشكل الافتراضي للشخصيات |

## 🎮 التحكم

| | كمبيوتر | موبايل |
|---|---|---|
| مشي / ركض | W A S D أو الأسهم / Shift | الجويستيك |
| لف الكاميرا | سحب بالماوس، والعجلة للزوم | سحب بالإصبع |
| تفاعل | E أو كبسة على الشي | زر ❤ أو كبسة |
| بوضع التأمّل | ← → للتنقل، Esc للرجوع | الأزرار تحت |

التقدّم والأشكال بينحفظوا بالمتصفح. زر ؟ ← «غيّر الشكل» أو «ابدأ من الأول».

## 🌍 تبعته لحدا؟

ارفع المجلد كامل على استضافة مواقع ثابتة (Netlify Drop أو GitHub Pages). شغّل `start.bat` مرة قبل الرفع ليتحدّث `photos/manifest.json`.
